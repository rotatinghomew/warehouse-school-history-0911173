# 机构资料与活动口径

学校使用稳定 school 标识，学段和地区不是学校身份的一部分。所有业务日期以报送地日历表示，区间左闭右开。

## 三类原始事实

- **主档归属** `assign`：学校在业务日期区间上的已知学段与地区，互不重叠。可选 `known_at` 记录获知时间，缺省视为一开始即已知。
- **主管单位补报** `claim`：追加型、不可变。携带更正标识、学校、覆盖的业务日期、学段地区、获知时间 `known_at`、业务生效时间 `effective_from`、被撤回的更正标识 `supersedes` 与来源说明 `note`。
- **活动** `ingest`：事件标识、学校、业务日期、参与人数与来源批次。原始活动日与原始参与人数永不因更正而改写。

获知时间与业务生效时间是不同的事实：`known_at` 决定"当时是否已经知道"，`effective_from` 决定该声明从哪个业务时点起解释历史。没有明确优先关系的相交矛盾声明保留为争议，不虚构哪个主管单位更权威。相同更正标识、不同内容不是同一输入，会整条拒绝。

## 更正如何生效

生效归属是派生结果，由主档与有效补报按业务日期分段求值，不做就地改写：

1. 被其他补报 `supersedes` 的补报整体失效，这是撤回的唯一表达方式。
2. 某业务期间内仍有效的补报若学段地区一致，即由该补报解释。
3. 若仍有至少两份内容不一致且互不替代的补报，该期间标记为**争议**，不按到达顺序或获知时间挑选。只有显式替代才能消除争议。
4. 补报未覆盖的业务日期继续沿用主档；补报可以只覆盖原归属区间的一部分。

活动按业务日期重新挂接归属片段。没有学校资料的学校保持**未归属**，资料补齐后自动进入相应统计；争议期间的活动同样不进入学段汇总。

## 查询

- `organizations.view(db, school, day)`：某个业务日期应归属哪里（按当前全部已知信息）。
- `organizations.view(db, school, day, as_of=...)`：还原某个已知时点当时掌握的解释。
- `organizations.intervals(db, school, as_of=...)`：完整归属时间线。
- `organizations.claims(db, school)`：全部补报，包括已被撤回的。
- `facts.detail(db)` / `releases.summary(db)`：当前口径明细与分学段汇总，均反映最新更正。
- `releases.summary_as_of(db, as_of)` / `facts.detail_as_of(db, as_of)`：当时口径。
- `projection.audit_log(db, school)`：哪些原始事实被追加、哪些派生区间与活动因此改变、由哪条事实触发。

## 月度摘录与当前口径

月度摘录 `publish` 是已对外引用的固定结果，写入后不可变，后续更正不会改写它。当前查询与固定摘录不是同一个发布对象：更正只改变当前明细与分学段汇总，历史摘录保留原解释。`snapshot` 在同一事务内同时取明细与汇总，不会读到二者错配的中间状态。

## 事务与幂等

更正、重算、活动重挂接与审计写入处在同一个 `BEGIN IMMEDIATE` 事务内，崩溃或重启后要么整块生效、要么整块不生效。同一补报重复传送返回 `duplicate`，不产生第二份归属；并发登记同一标识时只有一条能插入。`projection.rebuild` 可随时由原始事实重建派生投影，结果与增量刷新一致。

匿名活动人数是按活动汇总的人次，不声称自然人去重。月度归属可以因主管单位的业务更正变化，不改变原始活动发生日和原始参与人数。
