# 机构资料与活动口径

学校使用稳定school标识，学段和地区不是学校身份的一部分。所有业务日期以报送地日历表示，区间左闭右开。现有assign只登记互不重叠的已知归属，不处理对已登记历史的更正。

主管单位补报资料可携带独立更正标识、学校、所覆盖业务日期、学段地区、获知时间、被撤回的更正标识与来源说明。获知时间与业务生效时间是不同的事实。没有明确优先关系的相交矛盾声明需要保留争议，不能虚构哪个主管单位更权威。原始更正与同标识异内容不是同一输入。

月度摘录是已对外引用的固定结果；当前查询与固定摘录不是同一个发布对象。匿名活动人数是按活动汇总的人次，不声称自然人去重。月度归属可以因主管单位的业务更正变化，不改变原始活动发生日和原始参与人数。
